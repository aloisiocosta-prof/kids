# Character photo adaptation

Use only when the user provides photographs and asks to portray those people as story characters.

## Consent and handling

- Confirm that the uploader has permission from the depicted person or, for a child, the parent/legal guardian to use the image for this book.
- Do not ask for unnecessary sensitive personal information.
- Never identify the person, infer or claim their real name, diagnose them or infer sensitive traits from the photo.
- Do not commit the photo, face crop, generated likeness sheet or private prompt to this public GitHub repository.
- Do not save the image as a persistent reference image unless the user explicitly requests that separate action and supplies/confirms the reference name.
- Keep temporary working assets in the private creation session and discard them when no longer needed where tools allow.

## Intake record per person

Record only what is necessary: user-assigned character name; role in story; permission to use the photo for stylized illustration; visible traits the user wants preserved; clothing/accessories to preserve or change; preferred fictional costume; and boundaries (what must not be depicted).

A photo does not establish the subject's name, age, relationship to the child, personality or consent.

## Character bible

After examining the photo, write a neutral visual description of visible features: hairstyle and color, eyewear, approximate visible face shape, skin-tone rendering palette, distinctive accessories and clothing if relevant. Avoid identity claims or sensitive inferences.

Define stable character anchors:
- face and eye shape/spacing;
- hair silhouette and color;
- eyewear/accessories;
- skin-tone palette;
- body proportions and height relationship;
- repeatable outfit/costume palette;
- characteristic expression and posture.

Use the same anchors, age depiction, costume, proportions and rendering style in every generated page. A change needs a narrative reason and a continuity note.

## Generation procedure

1. Create an individual portrait based on the supplied photo, transformed into an original magical-cartoon picturebook character.
2. Create front, three-quarter and full-body views and a small expression sheet if supported.
3. Generate a neutral group lineup to validate relative height, costume and palette when several characters appear.
4. Ask the user to approve or correct the designs before story scenes.
5. Reuse the approved generated character sheet as visual reference for each scene where supported.

## Prompt skeleton

Create an original children's picturebook character based on the user-provided photo. Preserve only these user-approved visible likeness cues: [approved anchors]. Transform the person into a warm magical-cartoon storybook character with soft rounded forms, expressive natural eyes, gentle painterly shading and a clean readable silhouette. Fictional character name and role: [user-provided]. Costume: [approved]. Plain neutral background, full figure, centered, no text, no logo, no watermark, no extra characters.

Do not introduce photorealism, caricature, age changes or family relationships not requested.
