# Book production orchestrator

Use whenever the user asks to plan, write, illustrate, assemble or deliver a personalized children's book.

## Mandatory sequence

1. **Intake:** read the full user brief and all supplied images, screenshots, PDFs and URLs that are technically accessible. Use reference-material-analysis and mark uninspectable parts UNKNOWN.
2. **Creative specification:** confirm title, age group, reading level, emotional theme, setting, cast, page minimum, output format and language. Reuse decisions already supplied; ask only for a blocking missing detail.
3. **Character preparation:** when photos are supplied, invoke character-photo-adaptation. Create a written character bible and approved visual reference sheet per character before scene generation.
4. **Narrative:** invoke children-picturebook-writing. Draft a complete beginning-middle-climax-ending arc and get human approval.
5. **Page plan:** invoke storyboard-30-pages. Produce at least 30 individually numbered narrative pages, excluding cover and end matter.
6. **Visual design:** invoke magical-cartoon-art-direction; establish palette, lighting, rendering language, proportions and environment rules.
7. **Image production:** invoke picturebook-illustration-production. Generate page art using the same approved reference assets and review continuity.
8. **Narration:** invoke narration-and-audio-script to align spoken text with final page prose.
9. **Layout:** invoke picturebook-layout after output format and trim size are established.
10. **Review and export:** invoke child-safety-and-editorial-review and book-export-preflight; deliver manuscript, page manifest, assets and export package.

## Approval gates

- No final page illustration before character designs and visual style are approved.
- No full illustration run before the complete 30+ page manuscript/storyboard is approved.
- No print-ready export before the printer's trim size, bleed, color profile and PDF requirements are known.
- No public repository commit containing personal photos, face crops or private generated character art without explicit permission for that exact publication.

## Project defaults

Initial project: "Uma Noite Mágica com Papai Noel", theme "coragem", visual direction "cartoon mágico". These are approved creative directions, not permission to invent the child's name, age, gender, family relationships or photo roles.

## Deliverables

At minimum: creative brief and evidence ledger; character bible and approved style guide; complete manuscript; 30+ page storyboard; illustrations and continuity log; narration script; assembled book file(s); QA report.

Do not call the project complete while any required page, illustration, narration or QA check is missing.
