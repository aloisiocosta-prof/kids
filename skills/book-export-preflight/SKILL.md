# Book export preflight

## Page manifest

The final package must contain cover; title page; dedication if requested; at least 30 narrative pages numbered contiguously from 1; credits/colophon; and back cover. Narrative pages are counted independently from cover and end matter. Generate a machine-readable manifest with asset paths and QA statuses. Reject missing pages, duplicate page numbers, empty text or unresolved illustration/narration assets.

## Image checks

- dimensions/aspect ratio match approved output;
- no broken/blank images or accidental placeholders;
- no cropped faces, hands, key props or text;
- sufficient resolution for output;
- no watermarks, logos, generated pseudo-text or unapproved real photographs;
- all pages maintain the approved character bible and visual style.

## Text and audio checks

- spelling, punctuation, names and pronouns checked;
- text legible and not clipped;
- high contrast and comfortable line spacing;
- text matches narration;
- page numbering and reading order correct;
- narration controls have accessible labels and keyboard/focus support.

## PDF/package checks

- open and inspect the actual exported file, not only source layout;
- verify page count from exported PDF metadata and render every page to images for visual inspection;
- confirm fonts are embedded or licensed and rendering stable;
- for print, validate bleed, trim, safe margins, color profile and resolution against the selected printer's published specification;
- run a privacy scan before attaching, uploading or publishing files.

## Report

Return total physical/PDF page count; narrative page count; missing or failed page assets; image/text/audio mappings; specification used; checks performed and not performed; and approvals still required.

Do not label the book print-ready if printer specifications are unknown.
