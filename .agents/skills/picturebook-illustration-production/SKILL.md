# Picturebook illustration production

## Prerequisites

Do not start full-page generation until the character bible and reference sheets are approved; the 30+ page manuscript/storyboard is approved; and global art direction and output aspect ratio are approved.

## Production procedure

1. Use the image-generation tool when creating or transforming illustrations.
2. Generate a small style-validation set: cover concept, group scene and emotion close-up.
3. Check character consistency against the approved stylized reference, not against any claimed identity.
4. Generate each page with one primary action and a composition suited to its page text.
5. Reuse the same character references and style bible for all pages.
6. Review each image immediately; correct identity drift, extra limbs/objects, costume changes, text artifacts, unsafe staging or inconsistent light.
7. Update the continuity log and store approved outputs in the private production asset set.
8. Run a final contact-sheet review to detect style drift across all pages.

## Continuity checklist

Face anchors, hair, skin-tone rendering, eye design and proportions stable; clothing/accessories stable unless story records a change; character count and relative heights correct; props persist and change hands/location consistently; time, weather and light progression make sense; expressions match the approved emotional beat; Santa's appearance is original and consistent; no unrequested text, watermark or logo.

## Asset naming

Use stable names such as page-001.webp through page-030.webp, with source prompt and review status stored in a private manifest. Never place raw character photographs in the public repository.
