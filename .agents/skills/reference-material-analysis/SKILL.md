# Reference material analysis

## Read every accessible source

- Open each exact URL and inspect the full accessible page content.
- Inspect each user-uploaded image individually at full available resolution; do not rely on filename or a previous summary.
- For PDFs, inspect every relevant page visually, not only extracted text.
- If a page uses a canvas, carousel, reader, lazy-loaded image or script-controlled viewer, state which controls and images could not be accessed.
- Do not say "read the entire book" unless every page image and its text were actually inspected.

## Evidence ledger

For each observation record source URL/file and exact page/step; what is visible; whether it is text, image, metadata or runtime behavior; classification OBSERVED, INFERRED, UNKNOWN or PRODUCT DECISION; and access limitations.

## Evidence already established for this project

The public Kidoo example "O Natal Gentil de Duda" identifies style "Cartoon mágico", 30 pages with narration, a five-year-old protagonist named Duda, grandmother Avó Lúcia, a dog named Mégui and a Christmas-night story awaiting Papai Noel. Its reader shell exposes page navigation, narration and reading settings and displays "1 de 18". The discrepancy between announced 30 pages and visible 18-unit reader count is unresolved; never equate the two.

Two user screenshots show:
1. a first selection screen with age bands 0–2, 3–5, 6–9 and 10+ and a progress label "Passo 1 de 8";
2. a protagonist screen with a two-word name limit, gendered character choice, exact age selection and optional personality description.

Do not copy the reference book's title, story, characters, page text, illustrations, UI copy or assets. Use only broad structural observations.

## Report output

Produce an evidence-backed reference report and a gap list before product decisions. Preserve discrepancies, omissions and uncertain details rather than silently inventing assumptions.
